# Gervigreindarleikir

This project contains several simple browser games built with HTML, CSS, and JavaScript. Each game lives in its own folder.

## Contents

- `SideBreakout2P/` - Two-player side-breakout game with score, lives, and multiple ball modes.
- `FightingGame/` - `Clash of Realms`, a fighting game with character select, 1P vs CPU, 2P local play, special moves, and rounds.
- `RacingGame/` - `Circuit Sprint`, a top-down racing game with 3 laps, lap timing, and a finish overlay.
- `PhoneInvaders/` - Space Invaders-style game where the player avoids and destroys enemies, scores points, and advances levels.
- `PongGame/` - Pong against the computer with scorekeeping, difficulty settings, and restart support.
- `NovaParachuter/` - `Nova Parachuter`, a falling parachuter game where the player dodges obstacles and earns points by flying through rings.

## Run

Open any of these files in a browser:

- `SideBreakout2P/index.html`
- `FightingGame/index.html`
- `RacingGame/index.html`
- `PhoneInvaders/index.html`
- `PongGame/pong.html`
- `NovaParachuter/index.html`
