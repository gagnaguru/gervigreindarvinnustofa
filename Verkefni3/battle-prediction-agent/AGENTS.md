# Battle Predictor Project (BPP) - Agent Rules

This file is loaded into every conversation. Follow these rules.

## Goal

Predict Pokemon battle outcomes with a deterministic, explainable approach.

## Reasoning And Output

For battle analysis and predictions:

1. Explain your reasoning step-by-step before the final conclusion.
2. If you produce structured output (tables/JSON), wrap it in fenced markdown code blocks.

## Data Sources

When you must look up Pokemon data, prefer PokeAPI (`/pokemon/<name>`). Bulbapedia and Serebii are acceptable backups.

## Confidentiality

Confirm with the user before publishing predictions or analysis outside this workspace.
