How to read all this
One run sends 3 Pokemon matchups to Codex using your AGENTS.md + SKILL.md. Each matchup is graded on the six axes; the table on the left shows the per-case breakdown.

Correctness sums up to 100 across the axes.
Cost penalty subtracts based on real dollars spent (price table × actual tokens).
Latency penalty subtracts based on total wall-clock seconds across the run.
Structural penalty subtracts based on the byte size of your editable files and your skill's description length. The description is always in context; long means expensive every call.

Want to improve? The axis bars below the score show where you lost points. Common wins: wire scripts/fetch_pokemon.py and scripts/type_matchup.py via SKILL.md; point at references/damage_formula.md for the math; stop loading references/competitive_meta.md; trim AGENTS.md aggressively.
