Vinnustofur í gervigreind þar sem við skoðum og ræðum hvernig gervigreind nýtist í þróun og rekstri. Fyrsta vinnustofan verður haldin 20. maí frá 14:00 til 17:00 í stofu M102 í HR.

Á þessari fyrstu vinnustofu munum við fara yfir helstu grunnatriði í gervigreind, tengdum verkfærum og vinnubrögðum. 

**Dagskrá vinnustofu:**
- **14:00-15:00:** Kynning á grunn hugtökum, mismunandi módelum, tengdum tólum og almenn umræða um gervigreind.
- **15:00-15:30:** Uppsetning á umhverfi.
- **15:30-17:00:** Verkefnavinna þar sem við leysum saman þrjú verkefni í kennslustofu til að læra handtökin.

Kennarar og verkefnastjórar:  
@Sævar Logi Björnsson, @Bjarni Þór Gíslason og @Magnús Valur Hermannsson.

**Markmið vinnustofunnar:**
- Setja upp umhverfi
- Skilja undirstöðuatriði
- Læra prompting
- Kynna MCP, Skills, Agent og tengingar við ytri kerfi (t.d. Asana)
- Prófa einfaldar lausnir

Öll verkefnin sem við vinnum á námskeiðinu verða aðgengileg í þremur möppum í þessu verkefni.


**Uppsetning fyrir vinnustofu**
1. Setja upp Codex:
   - Setja upp node.js til að fá npm.
   - Leiðbeiningar á: https://developers.openai.com/codex/cli

2. Setja upp Python:
   - Sækið nýjustu útgáfu af Python (mælt er með Python 3.10 eða nýrra) frá https://python.org.
   - Fylgið uppsetningarleiðbeiningum fyrir ykkar stýrikerfi (Windows, macOS eða Linux).
   - Athugið að haka við „Add Python to PATH" ef þið eruð á Windows.

3. Skoða verkefna repo:
   - Opnið verkefnasafnið (https://github.com/gagnaguru/gervigreindarvinnustofa) sem við vinnum með í Codex (ath. megið nota eigin uppsetningu ef viljið nota aðra lausn en Codex).
   - Tryggið að þið hafið aðgang að öllum möppum og skrám sem við notum í vinnustofunni.
